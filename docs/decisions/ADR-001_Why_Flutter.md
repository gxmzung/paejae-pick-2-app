# ADR-001: Why Flutter

## Status

Accepted

## Context

Paejae Pick 2 needs a mobile-first app structure that can support Android, iOS, and possible web preview.

## Decision

The project uses Flutter.

## Reasons

- Cross-platform development
- Fast UI prototyping
- Good fit for student service MVP
- Android release preparation possible
- Strong mobile app ecosystem

## Trade-offs

- Native integration still requires platform-specific work
- Store release needs additional policy and testing work
