# Paejae Pick 2 Documentation

This directory contains product, design, release, privacy, QA, and operations documents for Paejae Pick 2.

## Main Areas

- architecture: system structure and service flow
- decisions: product and technical decisions
- operations: local setup and release operation notes
- validation: assumptions, limitations, and review status
- design: UI and product design notes
- feature: feature-specific documents
- legal: privacy and policy documents
- qa: test and review documents
- release: release preparation documents

## Principle

Paejae Pick 2 should be documented as a smart campus MVP, not just a Flutter UI demo.
